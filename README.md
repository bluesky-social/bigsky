
# bigsky: original atproto relay implementation

This repository is a fork of [bluesky-social/indigo](https://github.com/bluesky-social/indigo) which contains the original "bigsky" relay implmentation and supporting packages.

This code is no longer actively maintained, and will be removed from the upstream indigo repository. But it contains a significant number interesting packages, protocol history, and implementation tricks, so it is mirrored here for public access.
